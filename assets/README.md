# 本地素材目录

公开源码不携带《崩坏：星穹铁道》角色、装备图片，也不携带米游社攻略缓存或 Wiki 数据。

程序首次运行后，会把用户通过公开接口读取的配置和攻略缓存放到 `CurrencyWarAssistantData/cache`。识别图标可以由用户在自己的电脑上手动校准并保存到 `CurrencyWarAssistantData/custom_icons`。这些本地文件不会进入源码仓库，也不会被程序上传。

After the first refresh, public configuration and guide cache are stored in `CurrencyWarAssistantData/cache`. User-confirmed icon crops are stored in `CurrencyWarAssistantData/custom_icons` and are never part of the public source.

初回更新後の公開設定と攻略キャッシュは `CurrencyWarAssistantData/cache` に保存されます。ユーザーが確認したアイコンは `CurrencyWarAssistantData/custom_icons` に保存され、公開ソースには含まれません。

如果你拥有某组素材的合法授权，可以在本机使用，不要把它们提交到公开仓库。
