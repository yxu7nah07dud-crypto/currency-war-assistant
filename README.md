# 货币战争实时助手

语言：**中文** · [English](README.en.md) · [日本語](README.ja.md)

Windows 10/11 本地悬浮助手。观察《崩坏：星穹铁道》货币战争画面，读取角色、商店和装备，在米游社公开攻略中匹配真实攻略码并提供运营建议。默认普通 A8·30，阵容不限。

## 使用

1. 打开游戏，进入货币战争。
2. 双击发行文件夹里的 **货币战争助手.exe**，选择游戏窗口，点击 **开始观察**。
3. 如果你已经从攻略广场复制攻略码，把它粘贴到顶部 **本局攻略码** 输入框，点击 **应用并锁定**。也可以点 **读取剪贴板** 后再应用；允许换行、空格和“攻略码：”前缀。锁定后整局只按这篇攻略的阶段阵容、抓牌优先级、装备与经济建议，点击 **新对局** 才会解除。
4. 准备阶段打开商店。查看 **现在怎么做** 中的买人、装备、经济和下一步建议。
5. 在 **攻略与备选** 里查看一个主推荐与两个备选。可以复制攻略码、打开官方原文，或者锁定阵容。
6. **已识别** 会列出助手当前依据的信息。双击条目或点击 **识别纠正**，补充未显示的角色、装备、星级、团队等级和已选投资。出售、升星或合成后核对记录。
7. 布局不符时，点击 **查看画面 / 校准区域 / 学习图标**。框选位置区域并保存，或者框选一个完整头像/装备图标、选择名称，学习该图标。
8. 点击左上角 **设置** 可控制是否始终置顶和透明度（55%–100%）。窗口为横版布局，适合放在游戏侧边。
9. 点击左上角 **设置**，会在标题上方展开设置栏，可集中调整始终置顶、透明度、语言（中文 / English / 日本語）和主题（深色 / 浅色）。设置会在关闭助手时自动保存，下次启动继续使用。

**攻略码使用位置：** 游戏内“货币战争 → 攻略大全 → 输入攻略码”。助手的复制按钮复制的是官方原始代码。

窗口可通过标题栏移动、右下角调整大小，顶部按钮折叠。真正的独占全屏可能盖住普通置顶窗口；此时在游戏设置中手动使用窗口或无边框显示。捕获黑屏、游戏关闭或最小化时，助手停止生成新画面建议。恢复后自动继续，游戏重启需重新“找窗口”。

## 识别与建议的依据

- 图像与中文文字识别全部在本机完成，没有付费模型或密钥。
- 联网只读取米游社公开攻略和配置；不读取游戏进程内存，不发送按键或鼠标操作，不上传截图。公开源码不内置角色、装备图标、Wiki 资料或攻略全文。
- 助手窗口默认允许 Windows 截图和录屏；游戏识别仍使用指定游戏窗口的独立捕获，不会把助手窗口当成游戏画面识别。
- 首次运行需要点击“更新攻略”获取当前公开配置和攻略；网络不可用时使用本机此前生成的缓存，界面显示更新时间。源码仓库不分发预置缓存。
- 排除官方标记失效的攻略。旧版本攻略仍需核对当前角色与装备，正文里的特定练度、星魂、环境和旧倍率不等于已满足。
- 适配分数不是通关概率。前提不足时明确提示，不把“商店出现核心”当作“已持有核心”。角色名字“花火”和“火花”及不同玩法形态分别处理。
- 必需策略/环境只在已确认选择后满足；前提提取采用明确句式，作者隐含条件仍需查看原文。
- 小图标、亮光或遮住的星级会漏读。未显示的装备与投资不能自动确认。投资页面里的选项默认“待选”，只有手动确认后才作为“已选”。
- 可见前台、后台、备战区和库存以最新识别为准；漏读的角色需手动补充。隐藏角色暂时沿用最近观察；自动记录超过3分钟没有重新看到会移除，手动补充保留至本局结束。开始下一局请点“新对局”。
- 手动移除的误识别会在本局被抑制；再次添加同名角色/装备或开启新对局后恢复识别。已装备物品可以手动指定给哪个角色。
- 手动商店是临时记录；手动刷新后点击“清除手动商店”，恢复自动读取。
- 单局持有角色和装备不在重启后恢复，避免把上局库存用到新局；区域校准和学习图标会保存。

## 文件与诊断

保持 `.exe` 和 `_internal` 在同一文件夹，不要只复制单独的 `.exe`。直接打开程序，不需要打开终端。程序首次加载本地模型可能需要数秒。

“助手数据”文件夹保存校准、图标学习、公开攻略缓存和日志。“导出诊断”保存识别结果，不会自动分享；正常运行不保存连续截图。该目录已加入 `.gitignore`，请不要上传。

## 开发与复现

Python 3.12，Tkinter，Windows Graphics Capture，RapidOCR/ONNX Runtime，OpenCV，PyInstaller。

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
.venv\Scripts\python.exe -m unittest discover -s tests -v
.venv\Scripts\python.exe -m PyInstaller --noconfirm assistant.spec
```

发行源代码包不包含游戏图像、攻略缓存、Wiki 资料或研究抓取结果。首次运行后由用户自行更新公开配置和攻略；`tools/diagnose_capture.py` 是自有捕获链路的只读校验工具。用于生成本地素材的准备脚本不进入公开源码包。

模型由 RapidOCR 包提供并随程序打包；依赖精确版本在 requirements.txt，完整开发环境版本在 requirements-lock.txt。

## 本机验证范围

已用实际1920×1080准备与战斗画面验证窗口捕获、五格商店、金币、团队等级、阶段与部分头像/星级；准备画面五件库存装备能保留重复数量。缩放识别和稳定画面检查、失效攻略、开局流萤前提、普通模式筛选、离线缓存、游戏关闭/最小化/过期截图用自动检查覆盖。

分析耗时显示在窗口中。准备画面预热后本机约2–3秒，首次加载更久；以商店变化五秒内更新为目标，低性能机器或切换动画可能超时。不同分辨率可校准，独占全屏的覆盖行为和完整游戏重启流程尚未逐项实机验证。

当前默认布局针对1920×1080。用960×540缩放图像测试时，商店与金币仍可读，头像、团队等级和部分装备有漏读，需要手动纠正或学习图标；不保证所有分辨率自动识别。
