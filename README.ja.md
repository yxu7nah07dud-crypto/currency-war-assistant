# 貨幣戦争リアルタイムアシスタント

投資環境・投資戦略の画面では、優先候補と各カードの効果、編成との関係、発動条件を比較します。攻略や編成が未確認の場合は汎用的な資源ルールのみを使用し、攻略固定後は作者の優先候補を参照します。認識不足は暫定と表示します。「認識済み」で不足する候補を追加してください。更新・画面移動で候補を消去し、実際に選んだカードは手動で選択済みにしてください。

言語：[中文](README.md) · [English](README.en.md) · **日本語**

『崩壊：スターレイル』の「貨幣戦争」を対象にした、非公式の Windows 10/11 用デスクトップ補助ツールです。ゲーム画面をローカルで観察し、表示中のキャラクター、ショップ、装備、所持金などを認識して、公開攻略コードとの適合理由と次の行動を案内します。

## 攻略コード検索とキャッシュの範囲（v1.0.3）

コード単体またはゲームの共有文全体を貼り付け、「適用して固定」を押します。キャッシュにない場合はオンラインでページを検索し、公式の詳細にあるコードと完全一致を確認します。「クリップボード読込」はタイトルも保持し、特性フィルターで検索を速めます。見つかり次第固定するため、全体同期の終了を待つ必要はありません。固定解除や新しい対局で、実行中の検索を取り消します。

「攻略更新」は通常モードの公開おすすめの人気順と新着順を、公式のページ情報に沿って最後まで読み取り、重複を除去します。旧版は各順の最初の3ページ（約60件）だけでした。ページ数、キャッシュ件数、コード付き件数と完了状態を表示します。終了や通信中断後も結果を保持し、次回に続きを取得します。初回の同期には数分かかる場合があります。

両方の一覧が終わった場合だけ「今回の公開おすすめ一覧を最後まで取得」と表示します。今回の通常モード公開APIで閲覧可能な一覧の範囲であり、過去・非公開・削除済み・ゲーム固有の条件付き攻略すべてを保証するものではありません。キャッシュが未完了または古い場合もあります。見つからなければタイトル付きの共有文全体で再試行してください。期限切れの攻略は固定せず、旧版攻略は現行キャラ・装備と作者の前提を確認します。検索状態は観察メッセージと別に表示します。

## 使い方

1. ゲームを起動し、「貨幣戦争」に入ります。
2. `CurrencyWarAssistant.exe` を起動し、ゲームウィンドウを選んで **観察開始** を押します。
3. 攻略コードをコピーした場合は、上部の **この対局の攻略コード** に貼り付けて **適用して固定** を押します。**新しい対局** を押すまで同じ攻略を使います。
4. **今すること** で購入、装備、経済、次の段階の提案を確認します。
5. **認識結果** から、判別できなかったキャラクター、星、装備、投資を修正できます。
6. 左上の **設定** を開くと、見出しの上に設定欄が展開されます。最前面表示、枠なしウィンドウ、透明度、言語、テーマを変更できます。設定は終了時に自動保存されます。
7. **枠なしウィンドウ** を有効にすると、助手のシステムタイトルバーを隠します。見出しをドラッグして移動、右下の三角をドラッグしてサイズ変更できます。**−** で最小化、**×** で終了。**Esc** またはチェック解除で枠を戻せます。この設定は助手ウィンドウだけに適用されます。

画面は中国語、英語、日本語に対応し、設定は終了時に保存されます。ゲームプロセスのメモリを読み取らず、ゲームファイルを変更せず、キーボードやマウス操作を送信せず、スクリーンショットをアップロードしません。

## 更新とキャプチャエラー

`CurrencyWarAssistant.exe` と `_internal` 全体を同じフォルダに保ってください。v1.0.2 ではキャプチャ用のネイティブモジュールを明示的に同梱し、配布版で実際の画像取得を検証します。旧版で `No module named 'windows_capture.windows_capture'` が表示された場合は、旧助手を終了し、新版全体を新しいフォルダに展開して起動してください。実行ファイルだけの置き換えでは不十分です。旧フォルダの `CurrencyWarAssistantData` を新フォルダに移せば、設定とキャッシュを引き継げます。枠なし表示への切り替えでは、不足したモジュールは修復できません。

助手の枠なし設定とゲームの表示モードは別です。ゲーム画像が黒い場合は、ゲーム側のウィンドウまたは枠なし表示を試してください。更新内容は [CHANGELOG.md](CHANGELOG.md) を参照してください。

## 公開ソースについて

公開ソースには、ゲーム画像、Wiki データ、攻略キャッシュ、攻略本文を同梱していません。初回更新時に公開設定と攻略メタデータをユーザーの `CurrencyWarAssistantData/cache` に保存します。このフォルダはリポジトリに追加しないでください。

本ツールは非公式のファンツールであり、miHoYo、HoYoverse、HoYoLAB、『崩壊：スターレイル』とは提携・承認関係にありません。ゲーム名、画像、データ、攻略内容の権利は各権利者に帰属します。詳細は [NOTICE.md](NOTICE.md) と [LICENSE](LICENSE) を確認してください。

## 開発

Python 3.12、Tkinter、Windows Graphics Capture、RapidOCR/ONNX Runtime、OpenCV を使用します。詳しい使用方法は [中国語 README](README.md) を参照してください。

配布版をビルドした後、`python tools/verify_release.py` でキャプチャモジュール、枠の切り替え、自作テストウィンドウの画像取得を確認できます。ゲームを操作せず、ゲーム画面も保存しません。

公開版にアイコンテンプレートは含まれません。ショップのカード名は OCR で読み取ります。前衛・後衛・控えのキャラクターと所持装備は「認識修正」で追加するか、ローカルでアイコンを学習してください。過去の顔画像・星数の検証では私有または学習済みテンプレートを使用しており、新規公開版の自動認識を保証するものではありません。

開発前に python tools/prepare_capture_wheel.py --install を実行してください。公式 2.0.1 wheel から依存宣言と配布バージョンのみを変更した 2.0.1+cwa.headless1 を作成します。元のコード、ネイティブバイナリ、ライセンスは保持し、OpenCV は headless の一種類に統一します。lock のローカル版は PyPI から直接取得できません。

開発依存関係は requirements-dev.txt（実行依存関係は requirements.txt）に分離しています。wheel の準備後、pip install -r requirements-dev.txt でビルド環境を用意してください。

認識は現在、簡体字中国語のゲームクライアントのみ対応しています。英語・日本語は助手の UI と生成提案の言語です。公式名称・効果・攻略本文は原文の中国語を保持します。完全同期後 24 時間以内は人気順 3 ページと新着の既知ページまでを更新し、所持変更では候補詳細のみ補います。完全同期で 2 回連続見つからない未固定攻略は削除します。検証は REVIEW-CHECKLIST.md を参照してください。
